# Tumbo

I build **living realities** — interactive 3D worlds you can drag, open, and play in.

## What I'm building

- **[maTumbo Living Reality](https://github.com/carltheghost/matumbo-living-reality-demo)** — a 3D glass-cube world: drag cubes anywhere in full 3D, double-click to travel inside them, real 3D chess (table console + full 3D avatar chess with Tumbo chibi pieces), plug-in bots, and a physics-driven fluffy Tumbo avatar (spring-physics fur, jiggle tails, squash-and-stretch landings). [Live demo](https://carltheghost.github.io/matumbo-living-reality-demo/).
- **[Steal the Moon](https://github.com/carltheghost/steal-the-moon)** — open data + specs for an interactive declassified-history story: the heist of Mimas. Real Saturn, fictional crime. One deterministic shared state, 24 screens, 7 simulation systems.
- **[Kage](https://github.com/carltheghost/kage)** — an interactive five-chapter night walk through a Kyoto mountain temple, rendered live in Three.js: lantern light, rain, drifting leaves, and a vermilion moon.

## How I work

- Vanilla JS + pinned three.js. Zero frameworks, hand-rolled deterministic math.
- Verified on phone and PC: zero console errors, zero mobile overflow — or it doesn't ship.
- Simulated points only. Never real money or wagering.
